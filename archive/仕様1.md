# このディレクトリの開発内容について
このディレクトリではレスキューロボットコンテストで使用する各種操作画面のダミーアプリを作成します。
ダミーアプリは複数のデバイスからそれぞれアクセスして表示するWebアプリ形式で表示されます。
ダミーアプリは下記の4種類があります。

- 操縦担当用アプリ(コントロールモード)
- 解析担当用ビュワー・報告アプリ(アナリティクスモード)
- 監視エンジニア用アプリ(エンジニアモード)
- 報告担当用スマホ向けアプリ(報告者モード)
- マスターモード

カッコ内はそれぞれアプリ内での名称です。
それぞれのアプリのヘッダーにこの名称を表示するようにしてください。

# 実装方法について
全てweb(HTML,CSS,JS)で作成してください。
TypeScript等のコンパイル必要な言語は使用しないでください。
サーバー等が必要であれば、FAST(Python) を使用してください

# テーマについて
基本的に若干グレーのダークテーマとします。
白色のボーダーでビューを区切り、複雑な背景・シャドウは設定しないでください。
テーマを統一し、ヘッダーにアプリ名を表示します。
文字は白色とします。
ヘッダーのみシャドウの使用を許可します。

# ビデオの扱いについて
アプリ内にカメラ映像を表示する個所がいくつかあります。
後程素材を用意するので、レイアウト確認用に適当な物を表示しておいてください。

# 各アプリについて
## コントロールモード
画面上部に通知の表示部を横幅100%出も受けてください。
報告者モードやエンジニアモードのアプリから文字列を受信して表示できるようにしてください。
通知が発生した時はオレンジベースの背景色にアニメーションするなど、目立つようにしてください。
通知表示部の下は画面を左右に3分割し、真ん中を最も広くとってロボットカメラの表示部とします。
左側には、タスクの進行状況をリスト表示します。
リストはDIV要素のブロック要素とし、完了であれば背景が変わるシンプルなものとしてください・
右側には各種ボタンを配置します。内容は一旦ダミーとしてください。

# アナリティクスモード
画面を2分割し、右側を30%,左側を70%としてください。
画面左側は上下に2分割し、上半分には4機体分の映像を2x2で表示してください。
下半分には1号機の映像を大きく表示してください。
右側の上部に「解析対象機体：〇号機」と表示されるようにしてください。
その下に横幅一杯に対象機体のカメラ映像を表示してください。
この対象機体はエンジニアモードから変更できるようにしてください。

その下に解析結果の表示・入力を行う枠を用意してください。
内容はsituation_reporterに準じます

# エンジニアモード
画面を2分割し、左側が30%,右側70%とします。
画面左側には1号機から5号機の通信状態(遅延、接続、接続方法(WiFi or TPIP))を表示してください。
また、コントロールモードが操縦している号機が分かるようにしてください。

1~5の数字を押すことで、各号機に関するメニューが大きくモーダル表示されるようにしてください。
モーダル画面には「割り込み要請1」「割り込み要請2」「解析要請1」「解析要請2」「通信方法切り替え」「機体無効化」「RaspberryPi 再起動」「ルーム指定」の選択肢がリスト表示されるようにしてください。
各リスト要素は・等は無しでブロック要素とし、asdfghjのショートカットで選択、選択後スペースで実行を促す表示に切り替わるようにしてください。

また、「割り込み要請1」を選択・実行するとコントロールモードのビデオ要素が指定した号機に切り替わるようにしてください。

画面右側は上下に2分割し、上半分には4機体分の映像を2x2で表示してください。
下半分には1号機の映像を大きく表示してください。

# 報告者モード
situation_reporterをベースとしてください。

# マスターモード
撮影進行に合わせてアナリティクスモードの画面に情報を表示するツールです。
簡素な造りで、ボタン動作でそうさするようにしてください。
