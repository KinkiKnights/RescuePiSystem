# 各モード 仕様（現行実装ベース）

最初の要求は [`../仕様1.md`](../仕様1.md) にありますが、その後の改修で内容が更新されています。
本書は**現在の実装が満たしている仕様**を、後から触る人向けに整理したものです。

共通テーマ: やや明るいグレーのダークテーマ／白ボーダーで区切る／影・複雑な背景なし／文字は白／
ヘッダーにアプリ名（ヘッダーのみ影あり）。色・寸法は `static/common.css` の CSS 変数に集約。

---

## 共通要素

- **通知バー**: 画面上部に全幅。`notification` を表示し、新着時はオレンジ背景でパルス（3 回）。
  control / analytics / engineer に表示。`RC.createNotifier()` で生成。
- **タスク進行状況**: 共通／ルーム A・B・C のグループ表示。各グループに進捗バー・完了数・
  対応号機バッジ（`room_units` 由来）。control / engineer はクリックで完了可能、analytics は閲覧のみ。
  `RC.renderTasks()` で描画。
- **音声 PTT**: 全画面に組み込み（`voice-client.js`）。PC はスペースキー、報告者モードは画面下部の送話ボタン。
- **映像ソース**: WebRTC（実機カメラ）のみ。号機 1〜5 → カメラ ID `RES1`〜`RES5`。
  中継先はマスターから設定。詳細は STATE_AND_PROTOCOL.md「映像」節。

## コントロールモード（`/control`）

- 上部に通知バー。その下を左・中・右の 3 カラム。
- **左**: タスク進行状況。
- **中央（最大幅）**: ロボットカメラ。操作機＋天カメの 2 画面表示や号機切替に対応。
  下部に解析結果タブ（部屋ごとの QR／顔色を表示・確定）。
  - 部屋ボタン（広場／暗室／2階）でタブ切替。
  - QR（負傷）・顔色は「確定する」⇔「撤回する」トグル（オレンジ＝未確定／緑＝確定）。
  - 顔色は色見本付きボタン、確定中はロック。内容は `room_analysis` でサーバー共有。
- **右**: 操作ボタン（現場到着・救出完了・再起動・通信経路切替・カメラ再起動）と機体選択・コントローラ選択。
  - 機体選択は選択中を水色背景、行動不能は赤表示。
- キーボード: 1–5=操作機切替、7=操作機のみ、8=天カメのみ、9=2 画面、0=両映像 等（画面下部バナー参照）。

## アナリティクスモード（`/analytics`）

- 上部に通知バー＋解析要請バー（Enter で承諾）。本体は 3 カラム（タスク／中央ビュー／解析入力）。
- **中央ビュー**: 大画面 1 つ＋右に幅 200px の縦タイル（天カメ・対象機・音声解析）。
  - タイルをタップ／クリックすると、その要素が中央へ移動（CSS grid-area で**複製せず移動**）。
  - 音声解析タイルは damiyan 検出器（実機）の Web ビューアを iframe 表示。号機→ポートは
    3→8771 / 4→8772 / 5→8773 で、`http://<location.hostname>:<port>/`（HTTP）を埋め込む。
    リモートPC からも見えるよう damiyan は LAN 公開（`--web-host 0.0.0.0`）で起動する。
    号機1／2 は検出器が無いため音声解析タイルを非表示にする。検出器 3 台は
    リポジトリ直下の `start-servers.sh detector`（`all` にも含まれる）で起動する。
  - 下部に号機選択ボタン（右詰め・25px 間隔、選択中は水色背景）。`set_analytics_target`。
- **解析入力（右）**: 部屋タブ（広場／暗室／2階、選択中は赤く光る）で部屋ごとに切替。
  - ストーブ（不明／無し／有り）・負傷状況（QR：読み取り中）・顔色（色ボタン）・備考。
  - 各項目に幅広の「確定する」⇔「撤回する」トグル。顔色の選択は**確定するまで他端末に反映しない**。
  - 内容は `room_analysis` でサーバー共有（control / reporter と双方向）。
- マスターからの撮影指示オーバーレイを全画面で表示できる。

## エンジニアモード（`/engineer`）

- 上部に通知バー。本体は左（タスク）／中央（映像 3×2）／右（接続情報・操作）の構成。
- 1〜5 号機の通信状態（遅延・接続・WiFi/TPIP）を表示。コントロールの操縦号機が分かる。
- 機体を選んで操作: 割り込み要請・解析要請・通信方式切替・行動不能（⇔復活）・Pi 再起動・ルーム指定。
  - 行動不能の機体は全画面で「行動不能」表示。行動不能時はボタンが「復活」に変わる。
  - ルーム A〜C ボタンで選択機体をその部屋の対応号機に設定（タスクの対応号機バッジに反映）。
  - 解析要請はアナリティクスへ要請を送る。
  - 再起動・通信切替は Ctrl 押下中のみ実行可能なガード付き。

## 報告者モード（`/reporter`） — スマホ向け・PWA

- iPhone 11 縦（414×896）想定。`manifest.webmanifest` でヘッダー無しの全画面起動（ホーム画面に追加）。
- **全部屋を常時並列表示**（タブ無し。情報は同時並行で来るため）。
- 各部屋カードに、ルーム名（**ルーム A/B/C を主表示**・場所名は控えめ）・対応号機バッジ・
  解析項目（ストーブ／負傷（QR）／顔色／備考）を表示。`room_analysis` をリアルタイム反映。
  - **備考は内容がある時のみ表示**。
- **報告の記録**: 各項目を**右スワイプで「報告済み」・左スワイプで解除**。報告済みは消えずに緑表示。
- **報告完了ボタン**（部屋ごと）: 押すと全項目を報告済みにし「報告済み：撤回する」に変化。
  - 実行時に他画面へ「ルーム X（場所）報告完了」を通知。
- **更新検知**: 報告済み項目が他画面から変更されると未報告に戻り、オレンジの点滅「更新」バッジが付く。
- 画面下部に**送話ボタン**（押している間だけマイク送話）。

## マスターモード（`/master`）

- 撮影進行用の簡素なボタン操作パネル。
- **映像（WebRTC）の中継先設定**・アナリティクスへの解析データ投入・
  解析対象号機の変更・撮影指示オーバーレイ表示／非表示・タスク完了送り（共通／部屋別）・
  **全体リセット**。操作ログを画面に表示。
