# video/ — カメラ映像素材

各画面に表示するロボットカメラ映像のダミー素材を配置するフォルダです。
**大容量のため Git 管理対象外**（`.gitignore` で除外）。リポジトリを clone した直後は空なので、別途素材を配置してください。

## 必要なファイル名

サーバー（`main.py`）と `static/common.js` の `videoBox()` が次の固定ファイル名を参照します。

| ファイル名 | 用途 |
|---|---|
| `1号機.mp4` | 1号機（天カメ）映像 |
| `2号機.mp4` | 2号機映像 |
| `3号機.mp4` | 3号機映像 |
| `4号機.mp4` | 4号機映像 |
| `5号機.mp4` | 5号機映像 |
| `全体カメラ.mp4` | 全体俯瞰カメラ映像 |

- 形式は `.mp4`（ループ・ミュート・autoplay で再生）。
- 該当ファイルが無い号機は、画面上で「映像 No Connect」プレースホルダーが表示されます。
- 配信は `main.py` が `/video` にマウント（`app.mount("/video", StaticFiles(directory="video"))`）。
